## 3. Interfaces (signatures, not prose)

- `charter.py`: `check(path) -> list[str]` (empty when the five parts, the five rows and the ceiling hold; each refusal names the part); `open(dir, goal, section, head) -> Path` writes `<dir>/<date>-<n>.md` (`n` one past today's highest) with the title, the table from the resolved `session` section (budget from `ceilings`, pin from `git rev-parse --short HEAD`, window, agents `0`), a Done-ness list whose first item is the charter itself, an empty Handover, a Next act line; `close(path, exit_text, meter) -> None` appends under Handover exactly one line `- exit taken: <text>; about <context> context, <turns> turns` (from `meter.json`; `meter unknown` when absent) and refuses when `check` refuses or the result would pass 4,096 bytes.
- CLI: `claude-session charter open <goal> [--dir D]` (default `charter.dir` of the resolved section, else `history/sittings`); `charter check <file>...`; `charter close [--exit TEXT] [<file>]` (default today's newest). Exit 0; 2 with the refusal on stderr; 1 on usage.
