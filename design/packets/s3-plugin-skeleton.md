## 3. Interfaces (signatures, not prose)

- `yamlsubset.load(text) -> dict`: mappings (nested by indentation), scalars (`null`, booleans, integers, quoted and bare strings), flat lists (`- x` and `[a, b]`), `#` comments, `{k: v}` flow mappings one level deep; raises `YAMLSubsetError(line, reason)` on anchors, multi-line scalars, nested lists, tabs, duplicate keys. `dump(obj) -> str` for the `.yaml` twin, deterministic key order as given.
- `resolver.resolve(cwd, session_id, env, profile=None, overlay=None) -> Resolved`; `Resolved.sections: dict[plugin, dict]`, `Resolved.provider: dict`, `Resolved.inputs: list[(path, sha256)]`; `resolver.write(resolved, state_dir) -> Path`; the layers read in the order quoted; a missing file is a skipped input, listed as `{"path": ..., "sha256": null}`. `state_dir = Path(env.get("XDG_STATE_HOME", "~/.local/state")).expanduser() / "claude-code-session"`.
- `hooks.session_start(payload) -> dict`: calls `resolve` with `payload["cwd"]`, `payload["session_id"]`; returns `{"hookSpecificOutput": {"hookEventName": "SessionStart", "additionalContext": "<one line: profile, ceilings, state path>"}}`; any failure returns `{}` after writing nothing and printing one line to stderr; exit 0 always.
- `doctor.run(env, cwd) -> Report`; `Report.checks: list[Check(name, ok, detail)]`, `Report.ok`; the check list of overhaul-r1 §2.4 in that order; `claude plugin list --json` is parsed for enabled plugins and versions; a dependency's version is compared against its range with a stdlib semver-range matcher supporting `^`, `~`, `>=`, `<`, `=` (tested); exit 0, 2, 1.
- `plugin/hooks/hooks.json`: `{"hooks": {"SessionStart": [{"matcher": "", "hooks": [{"type": "command", "command": "${CLAUDE_PLUGIN_ROOT}/hooks/run SessionStart"}]}]}}`; the exact key shape is checked against `claude plugin validate`, and if validate wants another shape the report says which.
- `profiles.yaml`: the six profiles of overhaul-r1 §1.3 plus `packets` and `builder`, every field of §2.1 present in `frontier` and inherited by the rest through a top-level `defaults:` mapping.
