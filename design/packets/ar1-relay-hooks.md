## 3. Interfaces (signatures, not prose)

- `package hooks`: `func Run(event string, stdin io.Reader, stdout io.Writer, env func(string) string, fx Effects) int` returns 0 always; unknown event, empty or malformed stdin: prints `{}`. `type Effects interface { StatusPorcelain(dir string) (string, error); Head(dir string) (string, error); ReadFile(path string) ([]byte, error); WriteFile(path string, b []byte) error; Now() time.Time }`; `OS` is the real one, `Fake` the test one (a map of dirs to porcelain and head, a map of files).
- PreToolUse: only `tool_name == "Bash"`; `tool_input.command` against `Guards`, one table `[]Guard{Name, Pattern}` in `guards.go`: `push` (`git` ... `push` in one pipeline segment), `amend` (`git` ... `commit` ... `--amend`), `rebase` (`git` ... `rebase`), `device` (a segment whose first word is one of `ssh`, `scp`, `sftp`, `rsync`, `mosh`, `telnet` or a word of `RELAY_DEVICE_VERBS`). A match prints `{"hookSpecificOutput":{"hookEventName":"PreToolUse","permissionDecision":"deny","permissionDecisionReason":"relay: <name>: <one sentence>"}}`; no match prints `{}`.
- Stop: stdin `session_id, cwd, stop_hook_active`. `stop_hook_active` true: `{}`. Dirty (any porcelain line): `{"decision":"block","reason":"relay: dirty-tree: <n> paths; commit the act or restore them, then stop"}`. Clean and `Head(cwd)` equals `start.json`'s `head`: block `relay: no-commit: nothing committed since <head>; commit the act, then stop`. No `start.json`: the no-commit check is skipped. At most 3 blocks per session (a counter in `start.json`); the fourth answer is `{"systemMessage":"relay: stopping after 3 nudges: <reason>"}`.
- SessionStart: stdin `session_id, cwd, source`. Writes `${XDG_STATE_HOME:-~/.local/state}/agent-relay/sessions/<session_id>/start.json` `{head, cwd, started, packet, blocks}`; on `resume` and `compact` an existing `head` is kept. When `RELAY_PACKET` names a readable file: `additionalContext` is one header line, `relay: this sitting builds <path>; commit per act; never push, amend or rebase; never a device; the Stop guard blocks a dirty tree`, then the file, capped at 16,384 bytes with a `[truncated]` line; otherwise `{}`.
- `cmd/relay/main.go`: `case verb == "hook"`: `return hooks.Run(event, os.Stdin, os.Stdout, os.Getenv, hooks.OS{})`, `event` empty when absent; `main_test.go` keeps its `hook Stop` row.
- `plugin/hooks/hooks.json`: `PreToolUse` (matcher `Bash`), `Stop`, `SessionStart`, each `${CLAUDE_PLUGIN_ROOT}/hooks/run <Event>`. `Makefile`: `test: go test -race ./...`.
- The six lines, on the branch. (1) `printf '{"session_id":"t","tool_name":"Bash","tool_input":{"command":"git push origin main"}}' \| go run ./cmd/relay hook PreToolUse \| grep -c '"deny"'` reads 1. (2) the same with `"git commit -m x"` reads 0. (3) `printf '{"session_id":"t","tool_name":"Bash","tool_input":{"command":"nasctl reboot"}}' \| RELAY_DEVICE_VERBS=nasctl go run ./cmd/relay hook PreToolUse \| grep -c '"deny"'` reads 1. (4) `D=$(mktemp -d); git -C "$D" init -q; touch "$D/x"; printf '{"session_id":"t","stop_hook_active":false,"cwd":"%s"}' "$D" \| go run ./cmd/relay hook Stop \| grep -c '"block"'` reads 1. (5) `printf '{"session_id":"t","cwd":".","source":"startup"}' \| XDG_STATE_HOME=$(mktemp -d) RELAY_PACKET=README.md go run ./cmd/relay hook SessionStart \| grep -c additionalContext` reads 1. (6) `test -d internal/hooks/testdata; echo $?` reads 0.
- Tests (`hooks_test.go`, table-driven, `Fake` effects, stdin from `testdata/<event>/<case>.json`, the expected stdout in `<case>.out`, exit asserted 0 every row): PreToolUse: push, push after `&&`, amend, rebase, `ssh`, a `RELAY_DEVICE_VERBS` word, plain commit, a non-Bash tool, garbage; Stop: dirty, clean without a commit, clean with a commit, `stop_hook_active`, the fourth nudge, no `start.json`; SessionStart: with a packet, without, oversized, `resume` keeping `head`, an unwritable state dir (still `{}`, exit 0).
