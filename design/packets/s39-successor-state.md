## 2. Rulings (the hq sitting's, reversible)

1. The state is the sitting's own file, in a fixed shape the tool checks; the tool writes none of its content, since no hook sees a helper return or a gate finish. The shape (`state.py`): a title line `# State for the successor of <sid-short>, <date> <HH:MM>`, then exactly four sections in this order, each a bulleted list or the line `- none`: `## Helpers` (one line per open helper: its name or description, its scratch directory, what it is doing, what wakes the sitting), `## Gates` (one line per gate or `agentik session gate` entry in flight: id, repo, the result path), `## Last acts` (at most three lines: a commit sha and what it did), `## Read first` (paths with line ranges, in the order to read them, and one line `- read nothing else before the first act`). Under 8,192 bytes, zero em-dashes. `state.check(text) -> list[str]` returns the shape faults; empty is good.
2. `checkpoint --respawn` gains `--state FILE`: the file is checked (a fault refuses the checkpoint, exit 2, the faults on stderr), then copied to `<chain home>/state.md` and described in `<chain home>/state.json` (`from_session`, `written`, `sha256`, `bytes`). `respawn.json` keeps exactly its five keys. Without `--state` the checkpoint behaves as today and prints one line to stderr, `no --state: the successor orients from the charter alone`. With no chain (`CLAUDE_SESSION_CHAIN` unset) and `--state`, the copy goes to `<state>/sessions/<sid>/state.md` and the line says the successor will not find it. `cmd_charter`'s `then:` line (347) names `--state <path>` as optional.
3. `session_start` prints, after the charter reminder, `; state: <chain home>/state.md (<bytes> B from <from_session short>, <HH:MM>): read it first, then the charter's Next act, nothing else before the first act` when the chain home holds `state.json` whose `from_session` is not this session and whose `written` is within 24 h; nothing otherwise. The block stays one line; the 320-byte bound of `rules.clause` is untouched since this text is outside the clause (the bound test reads the clause alone; the builder confirms `test_s21_bytes_at_the_bound` and names it in the report).
